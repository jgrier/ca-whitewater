## 2026-04-19: Class III document v1 → v2

### Source of corrections
Cross-reference pass against AW, cacreeks, awetstate, McQuoid, and commercial outfitter pages after initial v1 draft from editorial curation alone.

### Correction 1: NF Feather Tobin removed from Class III classics

**v1**: Listed in Tier 2 as "big-water III-V; the lower-flow III days are classics for strong III paddlers."

**v2**: Removed from Class III entirely. Tobin is a genuine Class IV run with sieve/tunnel hazards (awetstate: "don't come out thinking it is easy class IV"). McQuoid rates it V.

**Why v1 was wrong**: I was reading the Holbek/Stanley "III-V" rating as permission to call it III at low flow. Modern kayaker consensus does not support this. Tobin belongs on the Class IV list with a V flag, not on the III list.

### Correction 2: NF Feather Rock Creek promoted as the legitimate Class III NF Feather

**v1**: Mentioned only briefly under "NF Feather — Tobin and Rock Creek sections."

**v2**: Promoted to Tier 2 of Class III as its own entry. Rock Creek is explicitly pitched in local write-ups as "for the class III boater who is tired of the South Fork of the American" (awetstate). Dam-released summer/fall with one IV- rapid that scouts easily.

**Why**: Rock Creek is the actual III option on the NF Feather. It was buried in v1.

### Correction 3: Lower Kern split into two separate runs

**v1**: Listed "Lower Kern — Sandy Flat / town run / Powerhouse" as a single Tier 1 III classic.

**v2**: Split into:
- **Jungle Run** (Keysville → Miracle Hot Springs, ~6–7 mi) — the true Class III Lower Kern. Kept in Tier 1.
- **Miracle → Democrat** (~12 mi) — Class IV with mandatory V+ portage at Royal Flush. Moved to Class IV document.

**Why v1 was wrong**: I conflated two distinct runs. "Lower Kern" is ambiguously used in marketing. The commercial outfitter descriptions of Class III Lower Kern trips are almost always the Jungle Run; the commercially popular Miracle-to-Democrat run is Class IV.

### Correction 4: Mokelumne Electra downgraded from Tier 2 III to Tier 2 with clarification

**v1**: Tier 2 as "roadside II-III dam-release, popular with Sacramento paddlers and very close to Rocklin."

**v2**: Retained in Tier 2 but recharacterized. AW and cacreeks (Bill Tuthill) both classify Electra as Class II at normal flows, with II+/III only above ~1500 cfs. For an intermediate paddler this is a warmup run, not a Class III destination.

**Why**: v1 overrated Electra's difficulty. It's the best local beginner-to-intermediate run for Sacramento-area paddlers, which is a different claim than being a Class III classic.

### Correction 5: Tuolumne Main verified excluded

**v1**: Not listed in Class III.

**v2**: Verified correct. Multiple sources (AW, Whitewater Guidebook, every commercial operator) rate Meral's Pool → Ward's Ferry as Class IV+. The run starts with IV rapids (Rock Garden, Nemesis, Sunderland's, Ram's Head) at mile 0.1 and stays at IV+ through Clavey Falls.

**Why flagged**: Tuolumne is often casually called a "California classic" without the difficulty qualifier. It's a Class IV+ classic, not a Class III.

## 2026-04-19: Class V document v1 baseline

Produced with IV corrections baked in. No formal v1→v2 pass.

### Key decisions made during initial draft

1. **"V spreads enormously"** — explicitly split V into four buckets (easy V, solid V, stout V/V+, extreme expedition V) rather than treating it as a single category. Chamberlain at high water and the Middle Kings are both "V" but not the same sport.

2. **Tobin dispute noted in BOTH documents** (IV and V). Legitimate because both framings are defensible depending on whether you weight consequence or technical difficulty.

3. **Extreme V tier not ranked** — explicitly declined to rank Middle Kings, Royal Gorge Heath section, Upper Cherry Creek, etc. because this is beyond what sources alone can resolve.

4. **Darin McQuoid used as primary authority for V/V+** — his site and list at http://jscreekin.blogspot.com/ were the single most valuable cross-reference. Outfitter ratings at V level were distrusted in favor of McQuoid's kayaker-perspective ratings.
